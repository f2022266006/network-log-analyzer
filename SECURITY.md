# Security and Responsible Use

This is an educational defensive log-analysis project. Analyze only logs you
own or are authorized to inspect.

Do not commit real authentication logs to a public repository. They may expose
usernames, addresses, hostnames, timestamps, and infrastructure details. Use
sanitized data or the included sample, whose IP addresses come from ranges
reserved for documentation.

An alert is a request for investigation, not proof that a source is malicious.
Do not block, contact, or accuse someone based only on this tool's output.

To report a vulnerability, contact the maintainer privately and include a clear
description, reproduction steps, impact, and suggested mitigation if available.
